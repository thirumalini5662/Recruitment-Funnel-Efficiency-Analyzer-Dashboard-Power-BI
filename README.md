📊 Recruitment Funnel Efficiency Analyzer Dashboard | Power BI

This project presents an interactive Power BI dashboard designed to analyze recruitment funnel efficiency from application to hiring.

The dashboard transforms recruitment data into actionable insights covering candidate progression, stage conversion rates, hiring sources, time-to-hire, hiring trends, and cost per hire.

🔹 Key KPIs:
• Total Applications
• Candidates Screened
• Candidates Interviewed
• Offers Made
• Candidates Hired
• Average Time to Hire

🔹 Key Analysis:
• Candidates by Recruitment Stage
• Hires by Source
• Time to Hire by Department
• Stage Conversion Rate
• Monthly Hires Trend
• Cost per Hire by Source

🔹 Interactive Filters:
• Department
• Source
• Job Level
• Final Status

🔹 Tools & Technologies:
• Microsoft Power BI
• Power Query
• DAX
• Microsoft Excel
• HR Analytics
• Recruitment Analytics
• Data Visualization

This project demonstrates how recruitment data can be transformed into an interactive business intelligence solution to understand hiring funnel performance, identify conversion patterns, compare recruitment sources, and monitor hiring efficiency.
